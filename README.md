# Les cartes de Tartine

Flashcards and a quiz for the French words of the learning game LaConfiture2 – for the iPad (Safari → « Zum Home-Bildschirm »).
This folder is generated by `WebApp/bauen.py` in the game's project – don't change files here, they are overwritten.
